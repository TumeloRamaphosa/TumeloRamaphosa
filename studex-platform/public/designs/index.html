How these were chosen

The brief was vague (“give the design this”), so per the huashu-design methodology I entered Design Direction Advisor mode and picked three philosophies that genuinely differ on the axes that matter for a home-automation dashboard: tone (premium / friendly / utilitarian), density (sparse / medium / dense), and typographic register (serif / sans / monospace).

Anti-slop rules followed

  1. No purple neon gradients, no glow effects.
  2. No emoji icons; SVG glyphs only.
  3. No placeholder silhouettes; real device names and addresses.
  4. One accent colour per design, used with discipline.
  5. Magazine-grade typographic hierarchy and exact CSS Grid columns.
