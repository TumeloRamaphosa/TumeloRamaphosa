# StudEx Platform

"StudEx Cognitive Brain + Claw Platform" — a Next.js web platform in
`studex-platform/`. Tagline seen in the marketing page: *"Creating virtual to
reality farmers."* Owned by [[tumelo-ramaphosa]].

## Stack
- **Next.js 16 + React 19**, Tailwind 4, Framer Motion, Three.js
- **Supabase** (`@supabase/ssr`, `@supabase/supabase-js`)
- API routes for agents, chat, github, rocket
- Integrations referenced: Google Vertex AI, GitHub
