## Integration with Scroll-World Studio

### Sync Points

1. **On Project Creation**
   - Auto-generate vault structure
   - Create base concept notes
   - Initialize Analytics section

2. **On Scene Generation**
   - Update scene file with assets
   - Log generation metadata
   - Update performance baseline

3. **On Analytics Update**
   - Refresh metric tables
   - Update heatmap visualization
   - Flag optimization opportunities

4. **On User Edits**
   - Sync Obsidian changes to Scroll-World
   - Update scene briefs
   - Queue regeneration if needed

### Access the Vault

```
# In Scroll-World Studio
1. Go to Project Settings
2. Click "Export to Obsidian"
3. Download .zip file
4. In Obsidian: File → Open Vault → Select folder

# Keep in Sync
- Studio automatically pushes updates
- Your edits in Obsidian sync back
- Real-time collaboration ready
```
