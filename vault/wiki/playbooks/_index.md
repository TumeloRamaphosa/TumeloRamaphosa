# 📒 Playbooks

Repeatable, codified how-to's. When you do something twice, write the playbook so a
skill (or a teammate) can run it the same way every time. *Codify once, hand it off.*

## Starter set (to build out)
- [ ] **Product drop launch** — from teaser → countdown → drop-day social + email
- [ ] **Meta ad campaign** — audience, creative brief, budget, read-outs
- [ ] **SEO article → publish** — research, draft, on-page, internal links, schema
- [ ] **Weekly content sprint** — turn 1 article into 5 social posts + 1 video
- [ ] **Win-back campaign** — segment, message, offer, timing

> Each playbook should name the **skills** it uses and the **vault paths** it reads/writes.
