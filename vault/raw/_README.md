# raw/ — dumping ground

Everything lands here first. **Speed over polish.** No file here is trusted as final.

- Job results from the Mac mini hub → `raw/inbox/` (in) and `raw/<job-id>.md` (out)
- Scraped pages, Perplexity answers, transcripts, screenshots, voice notes
- Half-formed ideas, meeting scraps, link clippings

## Promotion rule

When something here proves **durable and reusable**, run `/vault-cleanup` to promote it
to `wiki/` — cleaned, sourced, and linked. Raw is allowed to be messy; `wiki/` is not.

Suggested naming: `YYYY-MM-DD-<source>-<slug>.md`
