# /weekly-review

Two modes — ask which, or infer from the day:

## Plan mode (Mon)
1. Read last week's review + the brand bible + Analytics domain targets.
2. Set this week's theme, product focus, and content calendar (per channel).
3. Save to `vault/outputs/reports/weekly/YYYY-Www-plan.md`.

## Review mode (Fri)
1. Read the week's data snapshots, briefs, and published content.
2. Score vs targets: revenue, orders, AOV, conversion, ROAS, organic sessions.
3. What worked / what didn't / double-down list for next week.
4. Then suggest running `/vault-cleanup` to promote winning learnings to `wiki/`.
5. Save to `vault/outputs/reports/weekly/YYYY-Www-review.md`.

## Rules
- Be honest about misses; tie every claim to a number in the vault.
- End with 3 concrete actions for next week, each mapped to a skill.
